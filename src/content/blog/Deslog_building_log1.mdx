## 第一份功能-防剧透文字
谁不希望在自己的网站上加入一个防剧透文字功能呢（当然还有图片）？防剧透文字的实现：通过检测光标/点击位置实现对文字模糊属性的转换。如果我们使用简单的``filter: blur(3px)``文字属性实现，文字就会很粗暴地被模糊处理。这样读起来就不太方便，也不符合我常用的论坛的防剧透文字样式。开发路径大概是
1. 先尝试使用filter属性，发现完全不符合我的预期。
2. 询问codex大人，原来这种效果是防剧透文字，codex大人实现了一版。
3. 进行一个Google寻找其他人的实现方式[Riya's Blog](https://awsl.tv/35)。
4. 回到codex，参考其他人的实现方式，把这项功能内置化实现。

### 悬停预览与点击保持

下面的文字可以操作：使用鼠标时，移入可临时查看，移出后重新模糊；点击则保持显示，再次点击取消保持。

<p>悬停或点击查看：<Spoiler>现在这一段应该就算还能阅读了。</Spoiler></p>

```astro
<Spoiler>现在这一段应该就算还能阅读了。</Spoiler>
```

取消保持后，如果鼠标仍停留在文字上方，悬停预览仍然生效，需要移开鼠标才会重新模糊。

### 仅点击显示

将 `mode` 设置为 `click` 后，鼠标经过不会显示内容，必须点击才会切换状态：

<p>点击查看：<Spoiler mode="click">还有持久化显示的噢。</Spoiler></p>

```astro
<Spoiler mode="click">还有持久化显示的噢。</Spoiler>
```

点击一个防剧透区域只切换它本身状态，点击空白或其他非防剧透区域不会取消保持显示；按 Escape 才取消全部保持。

## 从模糊样式到可切换状态

模糊本身由 CSS 完成，点击后的保持状态由按钮的 `aria-pressed` 属性记录。它同时向辅助技术表达按钮是否处于按下状态。

| 当前情况 | `aria-pressed` | 是否清晰 |
| --- | --- | --- |
| 初始状态 | `false` | 否 |
| 默认模式下悬停 | `false` | 是，移出后恢复 |
| 点击后保持显示 | `true` | 是，移出后仍显示 |
| 取消保持显示 | `false` | 由是否仍在悬停决定；仅点击模式立即恢复模糊 |

页面上的基本结构是一个按钮，内部的 `span` 包住需要模糊的内容：

```html
<button type="button" class="spoiler" aria-pressed="false">
  <span>这其实是一个大号按钮来着</span>
</button>
```

只模糊内部内容，可以让按钮的焦点轮廓保持清晰。`display: inline-block` 为内层文字建立可应用滤镜的盒子；`type="button"` 则避免按钮在表单中触发提交。

```css
/* 默认模糊 */
button:is(.spoiler, .spoiler-click) > span {
  display: inline-block;
  filter: blur(3px);
}

/* 点击后保持显示 */
button:is(.spoiler, .spoiler-click)[aria-pressed='true'] > span {
  filter: none;
}

/* 只有有光标的才能启用预览 */
@media (hover: hover) and (pointer: fine) {
  button.spoiler:not(.spoiler-click):hover > span {
    filter: none;
  }
}
```

`spoiler` 和 `spoiler-click` 共用基础样式，只有前者参与悬停规则。悬停不会改变 `aria-pressed`，所以临时预览与点击保持可以分别处理。

## 在页面与文章中使用

### Astro 页面

在 `src/pages/` 中的 `.astro` 文件顶部已有的 `---` 区间导入组件，再把标签放进现有页面正文：

```astro
---
import Spoiler from '../components/Spoiler.astro';
---

<p>普通文字中可以嵌入 <Spoiler>隐藏的内容</Spoiler>。</p>
<p>也可以要求 <Spoiler mode="click">点击后才显示</Spoiler>。</p>
```

### 普通 Markdown 文章

`.md` 文章不能直接导入 Astro 组件，但可以使用原生 HTML。由于文章布局已经加载了公共支持代码，写入下面这一行即可：

```html
文字中的 <button type="button" class="spoiler-click" aria-pressed="false"><span>隐藏内容</span></button> 可以点击查看。
```

对应效果：文字中的 <button type="button" class="spoiler-click" aria-pressed="false"><span>隐藏内容</span></button> 可以点击查看。

将 `spoiler-click` 换成 `spoiler` 就能启用悬停预览。保留内部 `span`，避免在按钮内插入空行、段落或列表；加粗等行内格式可直接使用 `<strong>`。按钮内也不应再嵌套链接、其他按钮或防剧透组件。

### MDX 文章

`.mdx` 在 Markdown 的基础上支持导入组件，所以可以直接使用 `<Spoiler>`。本篇文章也使用这种方式展示交互效果。[Astro Markdown 与 MDX 说明](https://docs.astro.build/en/guides/markdown-content/)

```mdx
import Spoiler from '../../components/Spoiler.astro';

这是一段普通文字，后面是 <Spoiler>需要隐藏的内容</Spoiler>。
```

这里的路径适用于 `src/content/blog/` 中的文章。导入语句写在文章信息区之后；文章信息区保留标题、摘要、日期等字段，不要把 JavaScript 导入写进 YAML。
