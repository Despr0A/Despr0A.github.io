这是一篇 MDX 示例文章。项目已经配置了 MDX 支持，可以在文字中嵌入组件。

## 什么时候使用 MDX

普通文章可以直接使用 Markdown。需要加入可复用的提示框、图表或交互示例时，再使用 MDX。

MDX 在 Markdown 的基础上支持 JavaScript 表达式和 JSX。下面的示例把一个现有组件放进了文章正文。

## 组件示例

import HeaderLink from '../../components/HeaderLink.astro';

<HeaderLink href="/blog">返回文章列表 →</HeaderLink>

上面的链接由组件生成，点击后会返回文章列表。它不需要额外的客户端 JavaScript。
